# med - MediCare Hospital Application

A modern Next.js and Postgres-based healthcare management web application built with TypeScript, Tailwind CSS, and Drizzle ORM.

## Features
- Doctor and department directory & profiles
- Patient booking and appointments system
- PostgreSQL database with Drizzle ORM
- Modern responsive UI with Tailwind CSS

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env` and set your database connection:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
